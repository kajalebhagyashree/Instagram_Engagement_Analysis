# Instagram Engagement Analysis

## Internship Project – Alfido Tech

### Project Objective

The objective of this project is to analyze Instagram user activity, engagement patterns, content performance, and hashtag usage to derive actionable insights and recommendations for improving social media engagement.

### Dataset Description

The dataset consists of Instagram-related information stored across multiple CSV files:

* users.csv
* photos.csv
* likes.csv
* comments.csv
* follows.csv
* tags.csv
* photo_tags.csv

The data includes user profiles, photo information, likes, comments, hashtags, and follower relationships.

### Key Findings

* Public accounts create greater opportunities for engagement.
* Certain content types attract more interactions.
* Highly engaged posts receive significantly more likes and comments.
* Popular hashtags are frequently associated with successful posts.
* Consistent posting improves visibility and audience reach.

### Recommendations

1. Maintain a consistent posting schedule.
2. Focus on high-performing content formats.
3. Use relevant and trending hashtags.
4. Encourage audience interaction through captions.
5. Monitor engagement metrics regularly.
